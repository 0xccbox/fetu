# Fetu

Минималистичный кроссплатформенный VPN-клиент на Flutter. Подключение к серверам по ссылке-подписке от вашего провайдера — одной кнопкой.

[![Flutter](https://img.shields.io/badge/Flutter-3.24%2B-blue?logo=flutter)](https://flutter.dev)
[![Dart](https://img.shields.io/badge/Dart-3.5%2B-blue?logo=dart)](https://dart.dev)
[![sing-box](https://img.shields.io/badge/sing--box-1.12-orange)](https://sing-box.sagernet.org/)

## Возможности

- **Простой интерфейс** — одна кнопка подключения и базовые метрики: скорость, трафик, время сессии.
- **Умный выбор сервера** — рекомендация по ответу провайдера и локальным замерам, а не только по пингу.
- **Несколько протоколов** — Hysteria 2, VLESS Reality, NaiveProxy, Mieru, Shadowsocks.
- **Автоматическое переключение** — при сбое протокола или сервера клиент сам переходит на резервный.
- **Раздельное туннелирование** — выбор приложений и сайтов, которые идут мимо VPN.
- **Тёмная и светлая темы**, русский и английский языки.
- **Два режима интерфейса** — простой и расширенный.

## Установка и запуск

Требования: Flutter 3.24+, Android SDK 35 (минимум API 24).

```bash
git clone https://github.com/0xccbox/fetu.git
cd fetu
flutter pub get
flutter run
```

На Windows можно запустить [run_app.bat](run_app.bat) и выбрать пункт **[1]**.

## Как пользоваться

1. Получите ссылку-подписку у вашего провайдера.
2. Вставьте её в приложении.
3. Нажмите «Подключить».
