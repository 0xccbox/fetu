> **Минималистичный, но мощный кроссплатформенный Flutter-клиент для защищённых мультипротокольных соединений с максимальной гибкостью.**

## 🎯 КЛЮЧЕВЫЕ ОСОБЕННОСТИ

### Для пользователей:
- ✨ **Минималистичный дизайн** — нулевая когнитивная нагрузка, всё интуитивно
- 🚀 **Автоматический выбор** — умный подбор сервера (не только по пингу!)
- 🌍 **Любые протоколы** — Hysteria 2, VLESS Reality, NaiveProxy, Mieru, Shadowsocks
- ⚡ **Живой failover** — автопереключение при сбое протокола/сервера
- 🎨 **White-label** — брендирование от провайдера (лого, цвета, ссылки)
- 📊 **Реальные метрики** — пинг через весь каскад, скорость, трафик
- 🛡️ **Split Tunneling** — выборочный обход блокировок
- 🔒 **Обфускация** — Salamander, Traffic Pattern, TLS Fingerprint, SNI Fragmentation

### Для разработчиков серверов:
- 🔧 **Гибкая настройка** — провайдер контролирует всё через JSON API
- 🌐 **Per-node DNS** — каждый сервер со своим DNS и блокировкой рекламы
- 🗺️ **Каскадная маршрутизация** — умная система каскадов (Москва → Германия)
- 📡 **Динамические серверы** — автообновление списка серверов и доменов
- 🤖 **Умный балансировщик** — провайдер управляет алгоритмом выбора сервера
- 📝 **Подробные логи** — раздельные логи для быстрой диагностики

### Для ИИ и разработчиков клиента:
- 📖 **95,000+ слов документации** — всё на русском языке
- 🤖 **31 архитектурное правило** — строгие принципы для любого ИИ
- 🧪 **Автотесты и контракты** — защита от поломок при рефакторинге
- 🔍 **Структурированные логи** — ИИ быстро находит проблему
- 📦 **Модульная архитектура** — feature-first, каждая фича изолирована

## 📱 ГЛАВНЫЙ ЭКРАН

На телефоне кнопка подключения и список серверов находятся на одной странице. При прокрутке панель становится компактной, а ссылки провайдера остаются над списком. В широком окне список слева, подключение справа. Без подписки основная кнопка открывает форму импорта; серверы берутся только из подписки. Умный выбор и пинг по каждому узлу — дальнейшие задачи, не часть текущего списка.

**Детальный дизайн:** [Анимация скролла V4](docs/active/ФИНАЛЬНАЯ_АНИМАЦИЯ_СКРОЛЛА_V4.md). **Проверка и ограничения:** [Главный экран V4](docs/active/PLAN_HOME_V4.md).

## 🚀 БЫСТРЫЙ СТАРТ

### Требования:
- Flutter 3.24+ / Dart 3.5+
- Android SDK 35 (минимум API 24)
- Android NDK 25.1.8937393+ (для интеграции libbox)

### Текущий статус:
✅ **Android-сборка с нативным ядром `libbox` (`sing-box 1.12.12`) готова** (ФАЗА 6 разблокирована)

- На Android интегрирован `libbox.aar` (`arm64-v8a` + `x86_64`), реализованы `FetuVpnService` и `FetuPlatformBridge`. Для iOS всё ещё требуется macOS/Xcode (`PacketTunnelProvider`).
- Перед изменением запускайте `flutter analyze`, `dart run tools/architecture_check.dart` и `flutter test`. Проверка на Android-эмуляторе описана в [плане V4](docs/active/PLAN_HOME_V4.md).

### Установка:
```bash
# Клонировать репозиторий
git clone https://github.com/0xccbox/fetu.git
cd fetu

# Установить зависимости
flutter pub get

# Запустить на эмуляторе/устройстве
flutter run
```

### Следующий шаг — интеграция libbox:
```bash
# 1. Установить Android NDK (через Android Studio)
# 2. Собрать libbox.aar
cd android/libbox
./build.sh

# 3. Подключить к VpnConnectionService
# (см. docs/БЫСТРЫЙ_СТАРТ_ПОСЛЕ_LIBBOX.md)
```

**Детальная инструкция:** [БЫСТРЫЙ_СТАРТ_ПОСЛЕ_LIBBOX.md](docs/БЫСТРЫЙ_СТАРТ_ПОСЛЕ_LIBBOX.md)

## 🔥 ПОЧЕМУ ЭТОТ ПРОЕКТ ОСОБЕННЫЙ?

### 1. **Универсальность без компромиссов**
- Не привязан к одному провайдеру — любой может подключить свои серверы
- Провайдер контролирует всё: DNS, маршрутизацию, брендинг, алгоритм выбора сервера

### 2. **Минимализм + Уникальность**
- Оригинальный UX/UI без визуального шума
- Нулевая когнитивная нагрузка — пользователь не думает, всё работает

### 3. **Живая failover-система**
- UDP глушат → переходим на TCP автоматически
- Сервер упал → следующий в каскаде
- Домен заблокирован → автосмена из резервного списка

### 4. **Гибкость для провайдеров**
- Per-node DNS — каждый сервер со своим DNS
- Умный балансировщик — провайдер управляет алгоритмом
- White-label — полное брендирование

### 5. **Документация для ИИ**
- 95,000+ слов на русском
- 31 архитектурное правило
- Любой ИИ (Claude, ChatGPT, Cursor) может продолжить разработку
